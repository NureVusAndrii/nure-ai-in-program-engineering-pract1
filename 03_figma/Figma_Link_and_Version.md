## Перевірка доступу для викладача

1. Відкрити посилання в приватному вікні браузера / з іншого акаунта.
2. Переконатися, що викладач може переглядати файл (Share → доступ на перегляд).
3. Запустити Present із S-02-A та перевірити All/Important, New Issue overlay, Cancel, validation, success, Details, Back.
4. Окремо відкрити REF-01..06 і перевірити права, переходи, comments, empty states.

**Обмеження:** експорт `.fig` не замінює ручного проходження інтеракцій; макет не реалізує справжню авторизацію, БД, HTTPS, backup чи response time.
